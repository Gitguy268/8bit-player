# 8-Bit Player

A chunky 8-bit stage and turntable player for your own audio files, in plain HTML.

</div>

There are two pages: `index.html` (the stage and turntable) and `vinyl-8bit.html` (a vinyl record player).

<!-- run-steps:start -->
## Run it locally, step by step

1. **Get the code:**

   ```sh
   git clone https://github.com/Gitguy268/8bit-player.git
   cd 8bit-player
   ```

2. **Open `index.html`** by double-clicking it. There is nothing to install or build.
